# BIGBLU AFRICA — V2

Version front-end du site basée sur le cahier des charges et la présentation institutionnelle fournie.

## Charte visuelle appliquée
La direction visuelle reprend les éléments visibles du logo fourni :
- bleu marine / bleu institutionnel
- bleu clair / cyan
- blanc
- formes circulaires et lignes évoquant le globe / la connexion
- rendu institutionnel, professionnel et africain

Le logo fourni par le client est utilisé comme asset `assets/bigblu-logo.jpg`.

## Aperçu
Ouvrir `preview.html` pour une version autonome de démonstration.
Ouvrir `index.html` pour la version structurée avec CSS et JS séparés.
